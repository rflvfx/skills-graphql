# skills-graphql

**APIs GraphQL** — schema, resolvers, subscriptions e otimização com DataLoader.

</div>

## 📋 Sobre

Implementação de um servidor GraphQL completo: tipos, queries, mutations, subscriptions e soluções para o problema N+1.

## 📂 Conteúdo

- `schema.graphql` — definição de tipos (User, Post, Query, Mutation)
- `resolvers.js` — resolvers com relacionamentos
- `subscriptions.js` — PubSub para tempo real
- `loaders.js` — DataLoader anti-N+1
- `server.js` — servidor funcional

## 🚀 Quick start

```bash
npm install
npm start   # Playground em http://localhost:4000/graphql
```

## 🧠 Tópicos cobertos

`schema design` `resolvers` `DataLoader` `subscriptions` `pagination` `query complexity` `federation`
